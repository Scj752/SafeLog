# SafeLog 学习引导

> 你拿到的不是一份“看懂就算”的代码，而是一条**关卡制练习路径**：
> 参考实现是标准答案，学习项目是填空卷，单元测试是阅卷老师。

## 1. 项目的两个角色

| 目录 | 角色 | 说明 |
| --- | --- | --- |
| `reference/` | 参考实现 | 完整可运行，4 个关卡测试全部通过 |
| `learning/` | 学习项目 | 与参考实现**同接口**的骨架；`src/*.cpp`（及 `blocking_queue.h`）中所有函数体都是占位 + `// TODO:` 提示 |
| `tests/` | 关卡测试 | 同一套用例编译两次：`ref_*` 链接参考实现（常绿），`learn_*` 链接学习项目（初始全红） |

**规则：先自己实现 TODO，跑绿对应关卡后，再打开 `reference/` 对比差异。**
对比时重点关注：你的锁粒度、谓词写法、异常处理与参考答案的差别。

## 3. 练习路径（关卡 1 → 4）

```
关卡1 同步核心 ──> 关卡2 格式化与文件 ──> 关卡3 异步日志 ──> 关卡4 工厂与宏
 (枚举/接口/原子)   (RAII/filesystem)    (线程/条件变量)      (工厂/单例/宏)
```

### 关卡 1：同步日志核心
- **先读**：`learning/include/safelog/log_level.h`、`logger.h`、`sink.h`、`console_sink.h`
- **再写**：`learning/src/log_level.cpp` → `logger.cpp` → `console_sink.cpp`
- **验证**：`cmake --build build -j && ctest --test-dir build -R learn_stage1_core_test --output-on-failure`
- **思考**：为什么 `WriteToSinks` 要拷贝 sink 快照而不是持锁遍历？`ShouldLog` 为什么用原子？
- **常见坑**：`ToString` 忘了 switch 外的兜底返回；`enum class` 不能直接和整数比较大小？（可以，作用域枚举自带关系运算符）

### 关卡 2：格式化与文件输出
- **先读**：`formatter.h`、`file_sink.h`（注意私有方法的锁约定注释）
- **再写**：`learning/src/formatter.cpp` → `file_sink.cpp`
- **验证**：`ctest --test-dir build -R learn_stage2_format_file_test --output-on-failure`
- **思考**：为什么 `std::localtime` 在多线程下是错的？`error_code` 重载和抛异常重载各自适合什么场景？
- **常见坑**：滚动时忘了先 `close()` 再 `rename`（Windows 上打开中的文件无法改名）；`current_size_` 少算换行符。

### 关卡 3：异步日志（本项目最难一关，预留充足时间）
- **先读**：`blocking_queue.h`（学习版里的 TODO 注释就是实现步骤）、`async_logger.h`
- **再写**：`learning/include/safelog/blocking_queue.h`（模板必须头文件实现）→ `learning/src/async_logger.cpp`
- **验证**：`ctest --test-dir build -R learn_stage3_async_test --output-on-failure`
- **思考**：析构序列为什么必须是 Shutdown→join→Flush？`WaitEmpty` 之后为什么还要抢 `write_mutex_`？
- **常见坑**：
  - `if (queue.empty()) cv.wait(lock)` —— 虚假唤醒 + 丢失唤醒双杀，必须用带谓词的 `wait(lock, pred)`；
  - 工作线程里没 catch 异常 —— 一次 IO 异常让整个日志系统静默瘫痪；
  - joinable 线程对象析构 —— `std::terminate` 直接崩溃。

### 关卡 4：工厂与宏封装
- **先读**：`logger_factory.h`、`log_macros.h`（宏已完整提供，读懂即可）
- **再写**：`learning/src/logger_factory.cpp`
- **验证**：`ctest --test-dir build -R learn_stage4_factory_test --output-on-failure`
- **思考**：Meyers 单例为什么线程安全？`static_pointer_cast` 和 C 风格强转的区别？
- **常见坑**：`Register` 用 `operator[]` 会覆盖同名 logger（应使用 `emplace` 并检查返回值）。
