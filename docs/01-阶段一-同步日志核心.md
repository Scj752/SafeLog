# 阶段一：同步日志核心

## 1. 阶段目标

打通最小可用链路：**构造日志记录 → 级别过滤 → 格式化（默认）→ 写入控制台**。
建立全项目的抽象骨架（`ISink` / `IFormatter`），后续阶段只做扩展、不改动本阶段核心。

## 2. 涉及模块与文件

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 日志级别 | `include/safelog/log_level.h` / `src/log_level.cpp` | `LogLevel` 枚举与字符串双向转换 |
| 日志记录 | `include/safelog/log_record.h` | 值类型 `LogRecord`，构造时捕获时间戳/线程 id |

| 控制台输出 | `include/safelog/console_sink.h` / `src/console_sink.cpp` | 线程安全的控制台输出端 |

## 3. 接口清单

```cpp
// log_level.h
enum class LogLevel { kTrace = 0, kDebug, kInfo, kWarn, kError, kFatal };
std::string ToString(LogLevel level);
std::optional<LogLevel> LogLevelFromString(std::string_view text);

// sink.h
class ISink {
public:
  virtual ~ISink() = default;
  virtual void Write(const LogRecord& record, const std::string& formatted) = 0;
  virtual void Flush() = 0;
};
using SinkPtr = std::shared_ptr<ISink>;

// logger.h
class Logger {
public:
  explicit Logger(std::string name,
                  LogLevel level = LogLevel::kInfo,
                  std::shared_ptr<IFormatter> formatter = nullptr);
  virtual ~Logger() = default;

  const std::string& name() const noexcept;
  void SetLevel(LogLevel level) noexcept;
  LogLevel level() const noexcept;
  bool ShouldLog(LogLevel level) const noexcept;

  void AddSink(SinkPtr sink);
  void Log(const LogRecord& record);
  void Log(LogLevel level, std::string message, std::string file = {}, int line = 0);
  void Trace/Debug/Info/Warn/Error/Fatal(std::string message);
  virtual void Flush();

protected:
  virtual void Dispatch(const LogRecord& record);   // 模板方法钩子（阶段 3 重写）
  void WriteToSinks(const LogRecord& record);

// console_sink.h
class ConsoleSink final : public ISink { /* Write / Flush */ };
```

## 4. 模块耦合

```
Logger ──依赖接口──> ISink <──实现── ConsoleSink
Logger ──依赖接口──> IFormatter（PatternFormatter 默认实现，阶段 2 完善）
Logger ──使用值──> LogRecord ──聚合──> LogLevel
```

- Logger 不认识任何具体 sink：`AddSink` 只接受 `ISink` 指针 → **依赖倒置（DIP）**。
- `Dispatch` 为 protected 虚函数：本阶段默认实现“写所有 sink”，阶段 3 的 AsyncLogger 重写它 → **模板方法模式**。
- `TestSink`（tests/common/test_sink.h）证明扩展性：不改一行库代码即可新增输出端 → **开闭原则（OCP）**。

## 5. 关键设计与线程安全

- `level_` 使用 `std::atomic<LogLevel>`（relaxed）：日志过滤是每调用路径上的热操作，必须无锁。
- `sinks_` 的增删用互斥锁保护；`WriteToSinks`/`Flush` 先**拷贝快照再解锁遍历**，临界区最小化，也避免 sink 回调重入死锁。
- `ConsoleSink` 内部持锁，保证多线程输出不交错；WARN 及以上走 `std::cerr`。
- `LogRecord` 默认成员初始化器在**调用线程**构造时捕获时间戳与线程 id —— 这是阶段 3 异步化的关键前提。

## 6. C++ 学习点

1. `enum class` 对比传统枚举：作用域隔离 + 禁止隐式 int 转换。
2. `std::optional` 表达“可能失败的解析”，替代魔法值（如 -1）。
3. 纯虚接口 + `= default` 析构 + `override/final` 的现代多态写法。
4. `noexcept` 的正确使用位置（简单 getter/原子操作）。
5. 模板方法模式：`Log`（不变骨架）调用 `Dispatch`（可变钩子）。
