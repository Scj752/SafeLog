# 阶段四：工厂与宏封装

## 1. 阶段目标

提供开箱即用的门面（Facade）：
- `LoggerFactory`：用配置对象一句话创建同步/异步、控制台/文件任意组合的 logger；
- `LoggerRegistry`：按名字管理 logger，并提供全局默认 logger；
- 日志宏：一行输出，自动携带源文件/行号，且“先过滤再求值”零浪费。

## 2. 涉及模块与文件

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 工厂与注册表 | `include/safelog/logger_factory.h` / `src/logger_factory.cpp` | `LoggerConfig` / `LoggerFactory` / `LoggerRegistry` |
| 日志宏 | `include/safelog/log_macros.h` | `SAFELOG_*` 宏族 |

## 3. 接口清单

```cpp
// logger_factory.h
struct LoggerConfig {
  std::string name = "app";
  LogLevel level = LogLevel::kInfo;
  bool async = false;                 // true → AsyncLogger
  bool console = true;                // 附加 ConsoleSink
  std::string file_path;              // 非空 → 附加 FileSink
  std::size_t max_bytes = 0;          // 滚动阈值，0 = 不滚动
  std::size_t max_files = 3;
  std::string pattern = "[%d %t][%l][%T] %m";
  std::size_t queue_capacity = 8192;
};

class LoggerFactory {
public:
  static std::shared_ptr<Logger> Create(const LoggerConfig& config);
};

class LoggerRegistry {                  // Meyers 单例
public:
  static LoggerRegistry& Instance();
  bool Register(std::shared_ptr<Logger> logger);   // 重名拒绝 → false
  std::shared_ptr<Logger> Get(const std::string& name) const;
  void SetDefault(std::shared_ptr<Logger> logger);
  std::shared_ptr<Logger> Default() const;
  void Clear();                        // 测试隔离用
};

// log_macros.h
SAFELOG_INFO(logger, msg);   // 显式 logger（TRACE/DEBUG/INFO/WARN/ERROR/FATAL）
SAFELOG_I(msg);              // 默认 logger（SAFELOG_T/D/I/W/E/F）
```

## 4. 模块耦合

```
log_macros ──> LoggerRegistry（取默认 logger）+ Logger（过滤/写）
LoggerFactory ──创建──> Logger / AsyncLogger / ConsoleSink / FileSink / PatternFormatter
LoggerRegistry ──持有──> Logger（按名共享所有权，shared_ptr）
```

- 门面层单向依赖下层，**可整体裁剪**：不要工厂/宏也能直接用核心层。
- 工厂内部对 `AsyncLogger → Logger` 用 `std::static_pointer_cast` 向上转换：继承关系在编译期可知，转换零开销且类型安全（不能用 `static_cast` 之外的 C 风格强转）。
- 宏只依赖 `ShouldLog + Log` 两个公共方法 → 对 `shared_ptr<Logger>` 及其子类一视同仁（里氏替换）。

## 5. 关键设计与线程安全

- **Meyers 单例**：`static LoggerRegistry instance;` —— C++11 起静态局部变量初始化线程安全，无需双检锁。
- **注册表全方法持锁**：`Register/Get/SetDefault/Default/Clear` 共用一把互斥锁；返回 `shared_ptr` 拷贝，调用方持有的 logger 不会被注册表操作影响生命周期。
- **宏的两次保护**：
  1. `do { ... } while (0)` 使宏在 `if/else` 中作为单条语句安全展开；
  2. 先 `ShouldLog` 再 `Log`：被过滤时消息表达式中的拼接/格式化完全不发生（虽然本例消息在宏参数求值时已构造，但 `Log` 内部的记录构造与分发被跳过；若未来支持流式/惰性求值，此结构不变）。
- **`__FILE__`/`__LINE__` 捕获**：宏展开处即调用点，因此源位置精确指向业务代码行。

## 6. C++ 学习点

1. 简单工厂 + 配置对象：聚合 8 个参数，避免“参数地狱”构造函数。
2. 单例模式的现代实现（对比双检锁、`std::call_once` 的复杂度）。
3. 宏的正确姿势：`do-while(0)`、参数加括号、多语句安全、`#`/`##` 之外的实用边界。
4. `static_pointer_cast` 与继承体系中的智能指针转换。
5. 门面模式：子系统复杂度封装，调用方只面对 `Create + 宏`。
